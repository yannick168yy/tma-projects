## 2、有效首存定义（本合作核心口径，优先于一切口头约定）

一笔充值同时满足以下**全部**条件才计入结算：

1. 单笔实充 **≥ ₱200**，且到账成功（`status=paid`）
2. 该账号**历史首次**成功充值
3. 注册来源渠道字段（`bg_user_attribution.channel_code`）**精确匹配**该投手绑定的像素/渠道标识
4. **通过风控**：同设备指纹 / 同 IP / 同收款账户去重后仅计 1 个；被风控标记为可疑（刷单、代充、多开）的不计入
5. 充值后 **24 小时内未原路退款 / 撤单**

> ❗ **注册数、试玩金领取数、APK 下载数一律不作为结算依据**，仅作为过程指标参考。

## 3、测试预算（阶段式）

**1️⃣ 首次合作测试 — 单像素预算 $200/天**
次日 KPI 异常偏高 → 直接关停，不商议。

**2️⃣ KPI 优化到 $12–13** → 可增开 1–2 条像素，老线预算提到 $300/天。

**3️⃣ 广告成本稳定 $13 以内** → 预算提到 $500/天。
客均数据离谱需针对客均方向做对应优化，合作过程中会提醒，需第一时间从素材方向、人群受众等方向调整。

**4️⃣ 成本达标 + 客均达标双达标** → 进入拉量阶段（无限预算支持）。

> **开测时间要求：** 不接受周五开测。建议**周二 / 周三开新线**，用工作日低 CPM 完成素材筛选与
> 学习期，周末与发薪日（每月 **15 号、月末**）进入放量窗口。发薪日前需提前 1–2 天爬坡加预算，
> **禁止当天一次性猛砸**。

## 投放链接怎么拼

```
https://<投放域名>/?c=<渠道标识>&px=<FB像素ID>&tpx=<TikTok像素ID>&utm_source=facebook&utm_campaign=<广告系列>
```

- `c` —— **结算键**，一个投手/一条线一个值，对账全靠它；不传则退回 `utm_source`
- `px` / `tpx` —— 该条线的像素 ID，**从链接带入**，所以新增投放线不需要发版
- `fbclid` / `ttclid` 由广告平台自动追加，不用手写
- 首次带参进站即写死（first-touch），用户回访不改归属
