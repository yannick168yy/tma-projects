## 1. Telegram Bot 与 Mini App

| 项 | 决策 |
|----|------|
| Bot 用户名 | `@BetoGoBot` |
| Mini App short name | `BetoGo` |
| 生产 Web App URL | `https://www.188facai.com` |
| 品牌客服/社群 | **BetoGo**（链接待定） |

### 邀请链接格式

```
https://t.me/BetoGoBot?startapp=ref_{inviteCode}
```

- `inviteCode`：用户资料中的 6 位码（如 `BG8X2K`）
- BFF 登录时解析 `initData` / `start_param`，前缀 `ref_` 可选

### 邀请达标规则

| 规则 | 说明 |
|------|------|
| 绑定时机 | 新用户 **首次 TG 登录** 时写入 `referredBy` |
| 邀请人可 Claim | 被邀请人 **首笔成功充值 ≥ ₱100**（PHP 或 USDT 折算后） |
| 不满足 | 仅注册、未首充或首充 &lt; ₱100 → 邀请人 **不可** Claim |

## 2. 支付（Ammer Pay / Telegram）

| 项 | 决策 |
|----|------|
| 支付类型 | **Ammer Pay**（Telegram 内支付能力） |
| Provider Token | 已发放（**仅存 Nacos / 服务器 `.env`，禁止提交 Git**） |
| 充值币种 | **PHP**、**USDT**（USDT 按运营汇率折算入账 PHP 余额） |
| 通道 ID | `tg_wallet`（v0.1 契约不变） |

### 密钥存放

- `AMMER_PAY_PROVIDER_TOKEN` → Nacos `bff-node` / 生产环境变量
- 测试 token 格式示例：`{bot_id}:TEST:{secret}`（勿写入仓库）

### Webhook（待接）

- 公网 HTTPS 路径待定（如 `/api/v1/webhooks/ammer-pay`）
- 验签与订单状态机由 BFF 或 Java Core 实现

## 5. 多语言（i18n）

| 项 | 决策 |
|----|------|
| v0.2 首发语言 | **en**、**id**、**vi**、**zh-CN** |
| 移除 | ~~fil（菲律宾语）~~ |
| 默认策略 | 优先 **Telegram `language_code` / 浏览器 `navigator.language`** 匹配；无法匹配 → **en** |
| BFF | `Accept-Language` / `PATCH /user/me/language`；locale：`en` \| `id` \| `vi` \| `zh-CN` |
| 阶段 | **先前端静态文案**（vue-i18n），再 API 错误文案与运营配置 |

## 6. Nacos

| 项 | 决策 |
|----|------|
| 生产 2C2G | **默认不部署**；密钥在服务器 `.env`，BFF `BFF_STORAGE=mysql`（容器库） |
| 本地 / 4G+ | `docker compose --profile full` 或 `LOCAL_DEPLOY_FULL=1` 可启用 |
| Namespace | `batogo`（按运营命名；与品牌 BetoGo 拼写不同，以本字段为准） |
| Node BFF | 有 `NACOS_SERVER_ADDR` 时用 [`nacos`](https://www.npmjs.com/package/nacos) SDK；否则纯 env |
| 敏感项 | `TELEGRAM_BOT_TOKEN`、`AMMER_PAY_PROVIDER_TOKEN`、`GOOGLE_CLIENT_SECRET` 等 |

### 建议 dataId

| dataId | group | 消费者 |
|--------|-------|--------|
| `bff-node` | `DEFAULT_GROUP` | `apps/bff-node` |
| `core-java` | `DEFAULT_GROUP` | `apps/core-java` |

## 7. 服务器规格（按部署场景）

各场景 **内存 / vCPU / 磁盘 / Swap** 最低与推荐值、容器 cgroup 上限合计、宝塔同机禁忌，见：

**[docs/ops/SERVER-SIZING.md](../ops/SERVER-SIZING.md)**

| 场景 | 摘要 |
|------|------|
| A 当前生产（4 容器 + MySQL） | 2 GB 下限，**4 GB 推荐** |
| B 全量镜像（7 容器） | 4 GB 下限，**8 GB 推荐** |
| C 目标完整业务（真 Java Core） | 8 GB 下限，**16 GB 推荐** |
| D 本地开发 full compose | 本机 **8～16 GB** |
